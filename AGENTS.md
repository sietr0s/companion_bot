# Project collaboration

For new functionality, use the design interview workflow in
[grilling](.agents/skills/grilling/SKILL.md), via
[grill-me](.agents/skills/grill-me/SKILL.md). The user wants architecture and behavior
questions before implementation. Investigate repository facts yourself; present
recommendations, record answered decisions, and avoid asking settled questions again.
The interview applies to the new feature under discussion, not unrelated work already
approved. Routine fixes and verification can proceed within their existing scope.

Follow the module boundaries and layout in docs/adr/0002-module-boundaries-and-layout.md.
