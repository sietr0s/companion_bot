# Первое применение установленных навыков

2026-11-06. Область проверки: роутинг панели, форма входа, shell панели,
общий загрузчик промптов и существующие проверки архитектуры backend.
Это целевой обзор выбранных частей, а не полный аудит приложения.

| Навык | Применение |
| --- | --- |
| Python Design Patterns | Проверена отдельная ответственность общего файлового loader; дополнительный service/factory не нужен. Публичный контракт сохранён. |
| Python Testing Patterns | Проверены выход за каталог, недопустимые имена, JSON в обычном промпте, фигурные скобки в подставляемом тексте, отсутствие аргумента шаблона. Cache очищается между тестами. |
| React Best Practices | Защищённые страницы загружаются через React.lazy; общий layout остаётся смонтированным, Outlet имеет Suspense с доступным статусом загрузки. Используются React 18/Vite API. |
| JavaScript Testing Patterns | Добавлен сценарий входа: ввод через связанные labels, отправка формы, получение токена, переход в dashboard; mock API восстанавливается. |
| Web Design Guidelines | Добавлены aria-label кнопке темы, autocomplete логину/паролю и aria-hidden декоративным иконкам формы. |

Сборка разделяет страницы и тяжёлые таблицы/Markdown на отдельные chunks.
Entry-файл уменьшился с 1387 до 180 kB без gzip, но остаются общие chunks,
включая один размером около 523 kB. Размер entry не равен полной первой загрузке.

Проверены 350 backend-тестов, 30 frontend-тестов, Ruff, ESLint и production build.
Quality ratchet не показывает новых замечаний; существующий baseline сохранён.
Навыки установлены с исходными правилами и ссылками на зафиксированные версии,
условия их применения находятся в AGENTS.md.
