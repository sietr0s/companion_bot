# Поведенческие решения

`behavior` принимает два независимых решения: отвечать ли на входящий батч
(intake), затем каким способом отправить уже сгенерированный ответ (delivery).
Сервисы и политики не отправляют сообщения: это ответственность orchestrator.

## Intake

Действия — `respond` и `ignore`. JSON-классификатор получает последние 10 сообщений
с ролями User/Assistant и возвращает `needs_reply` / `asked_voice`.
Ошибка, timeout или некорректный JSON дают fail-open `needs_reply=1, asked_voice=0`.
`BEHAVIOR_INTAKE_TIMEOUT_S` по умолчанию — 60 секунд.
Политика учитывает флаги, короткое приветствие, активность и настроение.

## Delivery

Действия — `text` и `voice`. Учитываются длина текста, тип входящего сообщения,
серия голосовых ответов, предыдущий способ доставки, локальное время, активность,
настроение и запрос голосового. Жёсткие фильтры блокируют voice для Instagram,
коротких ответов и текстов с URL/числами по правилам `filters.py`.

Engine складывает base weights и вклады criteria, обнуляет запрещённые действия,
добавляет ±5% шума и выбирает из нормализованных неотрицательных весов.
`BEHAVIOR_SOFTMAX_TEMP` меняет резкость распределения; это не temperature LLM.
Масштабирование перед возведением в степень защищает от underflow/overflow.
При нулевой массе используются fallback `respond` / `text`.

## Состояние и расширение

`BehaviorAccountState` хранит activity/mood и время их следующего обновления;
ротация лениво выполняется при запросе. `BehaviorChatState` хранит способ последней
доставки и серию голосовых ответов. Timezone — `BEHAVIOR_TIMEZONE`, по умолчанию
`Europe/Moscow`.

- `criteria.py` — отдельные вклады в веса.
- `filters.py` — причины запрета действий.
- `policies.py` — состав criteria/filters, base weights и fallback.
- `engine.py` — расчёт и sampling, без SQL или внешних API.
- `repository.py` — persistence; `service.py` — orchestration решения.

Для нового правила добавлять criterion/filter и поведенческий тест, а не условие
в обработчик Telegram. Задержки доставки, Redis, stickers и HTTP управления mood
не входят в текущую реализацию.
